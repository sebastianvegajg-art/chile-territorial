# Chile Territorial · Demostración v0.2.0

Esta demostración autónoma reutiliza la interfaz del [PR #10](https://github.com/sebastianvegajg-art/chile-territorial/pull/10) para revisión visual. El corte `prueba-local` contiene únicamente cifras sintéticas.

## Abrir en Chrome

1. Inicia sesión en GitHub con acceso al repositorio privado.
2. Abre [Chile_Territorial_Demo.html](Chile_Territorial_Demo.html) y usa **Download raw file**. También puedes descargar [el ZIP](Chile_Territorial_Demo_y_Capturas.zip) y extraerlo.
3. Abre el HTML descargado en Chrome con **Ctrl+O** o **⌘+O**. El archivo incorpora JavaScript, estilos y datos. Funciona sin conexión ni servidor.

Selecciona las regiones y el año, cambia entre gráficos y tablas y prueba la descarga CSV. La opción de datos oficiales muestra que todavía no hay publicaciones oficiales en la demostración. Las capturas de 2013, 2019 y 2025 ilustran el selector anual.
